# GPT-2 block contract and workspace map

The layer is GPT-2's pre-norm decoder block with the `gelu_new` tanh
approximation:

```text
gelu_new(x) = 0.5*x*(1 + tanh(sqrt(2/pi)*(x + 0.044715*x^3)))
```

Packed QKV columns are contiguous `Q`, `K`, then `V`, each of width 768.
Within each region, head `h` owns columns `[64*h, 64*(h+1))`. Attention is
strictly causal: query `i` may attend only to keys `j <= i`.

## Quantization

For scale `s`, an FP32 value is stored as `Float8E4M3FN(value / s)` and read
as `stored.to(Float32) * s`. The fixed scales are:

| Tensor | Scale |
| --- | ---: |
| input hidden state | `1 / 448` |
| both LayerNorm outputs | `1 / 64` |
| packed QKV | `1 / 64` |
| attention context | `1 / 64` |
| GELU output | `1 / 64` |
| weights with K=768 | `(1 / sqrt(768)) / 448` |
| projection weight with K=3072 | `(1 / sqrt(3072)) / 448` |

No value generated by the evaluator saturates these fixed ranges. LayerNorm
uses epsilon `1e-5`; its affine weight and bias are FP32.

## Entrypoint tensors

The immutable arguments appear first:

```text
hidden                 [128, 768]    FP8
ln1_weight, ln1_bias   [768]         FP32
qkv_weight             [2304, 768]   FP8
qkv_bias               [2304]        FP32
out_weight             [768, 768]    FP8
out_bias               [768]         FP32
ln2_weight, ln2_bias   [768]         FP32
fc_weight              [3072, 768]   FP8
fc_bias                 [3072]        FP32
proj_weight            [768, 3072]   FP8
proj_bias              [768]         FP32
```

They are followed by evaluator-owned workspaces:

```text
norm1_workspace        [128, 768]    FP8
qkv_workspace          [128, 2304]   FP8
score_workspace        [1536, 128]   FP32
probability_workspace  [1536, 128]   FP32
context_workspace      [128, 768]    FP8
residual_workspace     [128, 768]    FP32
norm2_workspace        [128, 768]    FP8
mlp_workspace          [128, 3072]   FP8
output                  [128, 768]    FP32
```

Score row `head * 128 + query` contains all key positions for that head and
query. An optimized implementation may avoid either attention workspace.

## Correctness-first decomposition

A simple implementation can use one warp per LayerNorm row, one scalar dot
product per dense/attention output, one softmax row per CTA, and separate
FP8-quantizing epilogues. Once correct, replace dense scalar loops with the
Blackwell FP8 GEMM template and fuse only boundaries whose required FP8 round
trip is preserved.
